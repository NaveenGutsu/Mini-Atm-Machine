# Mini Python ATM Machine

A lightweight, interactive command-line ATM machine built in Python. This project demonstrates control flow using a `while` loop, user input handling, and basic conditional logic.

---

# Features

-  **Check Balance:** View current account funds in real time.
-  **Deposit Money:** Add funds with input amount validation.
-  **Withdraw Money:** Withdraw cash with overdraft protection.
-  **Clean Exit:** Graceful program termination using a boolean flag.

---

# Tech Stack

- **Language:** Python 3.x
- **Concepts:** `while` loops, conditional branching (`if/elif/else`), input validation, state management.
